Privacy & test details

This preview saves the exact location, message, timestamp and optional contact to the local database. It does not send a public SOS or check location restrictions.

Map tiles come from OpenStreetMap, which receives your network address and viewed map areas. The local database does not store sender IPs or device IDs; public-host logging has not been verified.

A future public map would show the location, message, timestamp and any contact you share. Your network connection is not hidden by this tool. See the connection guide.
