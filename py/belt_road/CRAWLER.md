# Crawler scope

[README.md](README.md) is the introduction and current implementation guide.

The early-stage pipeline is:

Find source URLs → fetch → extract locations and citations → SQLite → API → map.

There is no required review, draft catalogue or publication step. Source claims
are attributed, and users are asked to check the facts themselves. SOS Relay is
an information and SOS communication channel, not a certifying authority.

The supported Cambodia PDF adapter supplies source-coded sites and page citations.
Other formats remain document leads until an appropriate adapter exists. Later
work may add more source adapters, search discovery, source updates/corrections,
and discussion tools. These are future possibilities, not prerequisites for
running the current crawler. Operational commands belong in README.md.
